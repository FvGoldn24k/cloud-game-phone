# Cloud Game Phone

A deployable starter for a browser-based cloud gaming interface.

## Features

- Mobile-friendly cloud phone interface
- Clash Royale and Pokémon GO session buttons
- Node.js/Express backend
- WebSocket session connection
- Ready for deployment on Render

## Important

This project is a starter cloud-gaming interface. It does not include an Android virtual machine or the official games.

A separate authorized Android streaming/cloud infrastructure provider is required to actually run and stream Android games.

```bash
npm install
npm start
